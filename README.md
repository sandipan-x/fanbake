# FanBake

Convert oven temperatures between conventional and fan instantly — the 20°C rule both ways, time adjustments, and a quick dish table. Free.

## Features
- Two-way conversion: conventional ↔ fan with the 20°C rule
- Automatic 120°C minimum clamp with clear flagging
- Quick-reference table of common dishes with times
